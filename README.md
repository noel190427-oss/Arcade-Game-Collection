# 🎮 Noel Arcade Universe
**Created by [noel190427-oss](https://github.com/noel190427-oss)** • Contact: acade.game.support@gmail.com

## 🕹️ Included Games
1. **❌⭕ Tic-Tac-Toe Minimax**: Predictive AI with unbeatble Minimax engine.
2. **🧠 Memory Matrix**: 5 themes, streak combo multipliers.
3. **🍄🏃 Super Mario Run**: Raycast laser autopilot, double jump & 3s start countdown with retro synth sounds.
4. **🏁🏎️ Mario Kart Rush**: 50cc-300cc cups, drift boost, mystery items, traffic light countdown & rocket start.
5. **✊🖐️✌️ RPSLS**: Markov-chain prediction AI (Rock-Paper-Scissors-Lizard-Spock).
6. **🐍⚡ Neon Snake Retro**: Virtual touch D-Pad, neon fruit & VIP God-Mode screen-wrap.
7. **🧱💥 Cyber Brick Breaker**: Laser ball, multislice brick destruction & powerups.
